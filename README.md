# Nuts Farm — интерактивное портфолио

Самостоятельный сайт с локальным демо API. Telegram, авторизация, API-сервер, база данных, кошелёк и реальные платежи не нужны. Интерфейс использует Telegram Stars; все покупки виртуальные.

## Запуск

Нужен Node.js 20+.

```sh
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite. Переменные окружения и `.env` не требуются.

```sh
pnpm test:demo    # Проверки локальной игровой логики
pnpm build-check # TypeScript и production-сборка
pnpm preview     # Просмотр production-сборки
```

## Возможности демо

- Premium Nuts Pass, покупка уровней, бесплатные и Premium-награды, открытие коробок.
- Пазлы, Meta Match и Cryptle: уровни, сложности, энергия, победы, поражения и повторные попытки.
- Бесплатное и Premium-колесо, покупка билетов, выигрыши.
- Наборы карт, оформление Cryptle, коллекционные награды, бустеры и сборка предметов.
- Учебные курсы, викторины, покупка доступа, награды за уроки.
- Фарм с 30-секундным циклом, ежедневные награды, задания, достижения, друзья, рейтинги и история баланса.

Начальные ресурсы: 250 000 NUTS, 50 000 демо-Stars, 100 энергии, 15 бесплатных и 5 Premium-билетов. Кнопка **«Демо»** позволяет пополнить ресурсы или сбросить покупки и прогресс.

Состояние сохраняется в `localStorage` этого браузера. У каждого посетителя собственный прогресс. При недоступном хранилище демо работает до перезагрузки страницы.

## Изменение данных

`src/demo/fixtures.ts` — профиль, уровни, награды, товары, курсы и задания.

`src/demo/backend.ts` — локальные обработчики прежних API-маршрутов и изменение состояния. `src/redux/api/core.ts` подключает их к существующему приложению через RTK Query.

`src/demo/environment.ts` и `src/demo/telegram-sdk.ts` — браузерная замена Telegram-окружения, навигации, Cloud Storage и оплаты. Изображения, словари, Rive-файлы и WASM загружаются с самого сайта; звуки создаются локально.

## Публикация

Результат `pnpm build-check` находится в `dist`. Опубликуйте **всё содержимое** папки как статический сайт в корне домена. Для BrowserRouter настройте возврат `index.html` для маршрутов приложения (`/games`, `/pass`, `/earn` и т. д.). Для Netlify/Cloudflare Pages в сборку включён `public/_redirects`; для других хостингов нужна аналогичная SPA-настройка. Серверные функции не требуются.

Это демо для портфолио. Оно не подключено к экономике старого проекта и не отправляет уведомления реальным пользователям.
